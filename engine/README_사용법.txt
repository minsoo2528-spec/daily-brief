Daily Market Brief 폴더 사용법
================================

매일 하실 일은 하나입니다.
  → 한국자금중개 「일일 원화자금 현황」 PDF를 아침에 inbox 폴더에 저장해 주세요.
     (한국자금중개 홈페이지 > 시황자료 > 자금시장 동향 > 그날 올라온 '콜 레포 시장 동향' 첨부파일)
     파일 이름은 바꾸지 않아도 됩니다. 가장 최근에 저장된 PDF를 읽습니다.

나머지는 매 영업일 아침 자동으로 진행됩니다.
  1. 금리·뉴스·MMF·펀드 자금흐름·Repo 잔액 수집
  2. 고객 전달용 PDF 생성 → output 폴더에 저장 (예: 2026-10-19_Daily_Market_Brief.pdf)
  3. 팀 내부용 웹페이지 갱신 (같은 링크)
  4. 완료 알림

조건
  - 실행 시각에 이 PC가 켜져 있고 Claude 데스크톱 앱이 실행 중이어야 합니다.
    (금투협·예탁원 자료를 이 PC의 Claude 브라우저로 읽기 때문입니다.)
  - 자금중개 PDF가 없으면 그 섹션만 빼고 만들어집니다.

고객 발송 전
  - output의 PDF를 한 번 훑어보신 뒤 직접 메일로 보내 주세요. 자동 발송은 하지 않습니다.
  - 고객 배포 자료는 사내 준법감시 기준에 맞는지 확인하는 절차를 권장합니다.

폴더 구성
  inbox\    자금중개 PDF 넣는 곳
  output\   매일 생성되는 고객 전달용 PDF
  engine\   브리프 양식·스크립트·누적 데이터 (수정하지 마세요)
